# Trangie reference material

Source images that back the data in `data/courses/trangie/`. Keep these — if a
number is ever questioned, this is what we check against.

| File | What it is |
|---|---|
| `scorecard.jpg` | Photo of the physical Trangie Golf Club scorecard. Source for `data/courses/trangie/scorecard.json` |
| `hole-map-annotated.jpg` | Satellite view with all 18 tees numbered and an arrow from each tee to its green, annotated by JF |

The annotated hole map is the **authoritative source** for assigning OSM green and
tee polygons to hole numbers (gap G-1 in `docs/course-data-trangie.md`). Where OSM
has no polygon for a green, the arrow head on this map is where the pin goes.
